# Trying to Learn

Welcome to my first Minecraft Mod. I'm using it to learn. So far this adds 
*VeggieTales*-inspired blocks and items. I will also add more elements including non-*VeggieTales*.

## What this Mod Features 

Currently, this adds Items and Blocks like *Bob the Tomato*, *Larry the Cucumber*, Larry's Hairbrush, Veggie Diamonds and Tools and other *VeggieTales*-themed elements.

## Requirements
Fabric API, 1.21.1.

## In the future
This mod is currently called 'trying_to_learn' as well as the MOD_ID being called 'ttl', which stands for 'Trying to Learn'. Soon, I will rename it to VLNW, which this acronym will eventually be revealed of what it stands for.
